📊 Ad Campaign Performance Analysis (Power BI)
📌 Project Overview

This project analyzes digital advertising campaign data to understand ad performance across different audience segments.
The analysis focuses on impressions, clicks, audience attributes, and interests, presented through interactive Power BI dashboards.

The project is work-in-progress and will be expanded with more data, metrics, and visual insights.

📂 Dataset Description

The dataset contains ad-level performance data with the following fields:

🔹 Ad Details

ad_id

reporting_start

reporting_end

🔹 Audience Attributes

age

gender

interest1

interest2

interest3

🔹 Performance Metrics

impressions

clicks

spent

total_conversion

approved_conversion

🛠 Tools & Technologies

Power BI – Data visualization & dashboard creation

CSV / Tabular Data – Data source

DAX (planned) – For calculated metrics like CTR, CPC, and conversion rate

📈 Current Analysis & Visuals

The current report includes:

Age-wise distribution (Pie Chart)

Clicks vs Impressions (Bar Chart)

Overall campaign performance view

Clean canvas-based dashboard design

📊 Key Metrics Used

Impressions

Clicks

Click Through Rate (CTR) (planned)

Cost Per Click (CPC) (planned)

Conversion Metrics (to be added)

Identify high-performing audience segments
